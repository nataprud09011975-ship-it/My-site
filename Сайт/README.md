# Наталья Прудникова — дизайн интерьеров

Сайт-портфолио дизайнера интерьеров. Статический HTML, CSS и JavaScript — сервер не нужен.

## Состав

- `index.html` — главная страница
- `css/` — стили
- `js/` — скрипты
- `images/hero.png`, `images/about-natalia.png` — фото на главной и в блоке «Обо мне»
- `images/projects/` — фото проектов

## Как открыть локально

Откройте `index.html` в браузере. Если анимации или шрифты ведут себя странно, лучше запустить локальный сервер из папки сайта, например:

```bash
npx --yes serve .
```

## Как выгрузить на GitHub

1. Установите [Git](https://git-scm.com/download/win) и войдите в [GitHub](https://github.com).
2. На GitHub создайте **новый репозиторий** (без README, если файлы уже есть на компьютере).
3. В папке сайта выполните:

```bash
git init -b main
git add .
git status
git commit -m "Публикация сайта-портфолио"
git remote add origin https://github.com/ИМЯ_АККАУНТА/ИМЯ_РЕПОЗИТОРИЯ.git
git push -u origin main
```

Подставьте свой адрес репозитория вместо `ИМЯ_АККАУНТА/ИМЯ_РЕПОЗИТОРИЯ`.

## GitHub Pages (чтобы сайт открывался по ссылке)

1. В репозитории: **Settings → Pages**.
2. **Source:** Deploy from a branch.
3. **Branch:** `main`, папка `/ (root)`.
4. Сохраните. Через одну-две минуты сайт будет по адресу:

`https://ИМЯ_АККАУНТА.github.io/ИМЯ_РЕПОЗИТОРИЯ/`

Файл `.nojekyll` уже добавлен — GitHub Pages отдаёт файлы как есть.
