# FitWeek — приложение для похудения

Веб-приложение для людей, которые худеют: расписание тренировок, меню на неделю, напоминания и мотивация.

## Возможности

- **Сегодня** — мотивация дня, тренировка и меню на текущий день
- **Тренировки** — план на 7 дней (кардио, силовые, отдых, йога)
- **Меню** — сбалансированное меню ~1500 ккал/день на каждый день недели
- **Напоминания** — уведомления о тренировке, еде и воде (через браузер)
- **Прогресс** — серия дней, счётчик тренировок, календарь выполнения
- **Тёмная тема** — переключатель в правом нижнем углу

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080/fit-app/`

## Напоминания

1. Перейдите на вкладку **«Напоминания»**
2. Нажмите **«Разрешить уведомления»**
3. Настройте время и включите нужные напоминания

> Для работы уведомлений страница должна быть открыта в браузере (или разрешены фоновые уведомления).

## Данные

Прогресс и настройки сохраняются в `localStorage` браузера.

## Технологии

HTML, CSS, JavaScript — без зависимостей и установки.
